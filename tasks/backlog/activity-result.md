# Closing: verify, deliver, release

From the activity model (§5 close: verify the result, deliver it, release resources, record what
was learned). Learning is in `activity-log.md` and `estimate-learning.md`, this task is the rest.

## What

- **Verify**: on "Mark as done" show the acceptance criteria (see `activity-goal.md`) to check off;
  done with unchecked criteria asks once more
- **Deliver**: optional field `result` (what came out: text, a link to a file or entry); resources
  marked as deliverable in the Resources tab
- **Release**: unused budget and estimate go back to the parent's numbers (see
  `activity-resources.md`), the activity leaves "What next" and the agents' lists
- Close as one dialog: criteria, result, lessons, then status done (or failed/abandoned)

## Open questions

- Should acceptance be a checklist after all (open question in `activity-goal.md`)? Verifying is
  easier with one
