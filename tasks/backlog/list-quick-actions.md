# Quick actions in lists

From the UI sample: "a tea task is just a title and a checkbox", and children are added inline.

## What

- A done checkbox on Activity cards in lists (and in the tree, see `nav-tree.md`), sets status done
  without opening the editor
- Add a child inline: an input at the end of the list (or under a tree node), Enter creates it
- Close actions that need more (criteria, lessons, see `activity-result.md`) open the dialog only
  for activities that have criteria or an estimate, a small task is closed by the checkbox alone
