# Learning from closed activities

From the activity model (§2 model, §5 close, §7.7 learning = updating the model).

## What

- On close: compare estimate with spent effort (see `activity-resources.md`), store the ratio
- Show how accurate estimates are, overall and per kind of activity (type, tag, parent)
- When estimating a new activity: suggest a corrected value from the past ratio
- Lessons learned (see `activity-log.md`) of similar closed activities are shown when a new one
  starts; finding similar ones is a job for the agent
- Assumptions (see `activity-elements.md`) that turned out wrong are kept as lessons
