# Time-limited selection

Discussed 2026-10-29: tasks with a time limit exist but are rare. Low priority.

## What

- Optional front matter date, e.g. `selectedUntil: '2026-12-31'`, for a selection that ends
- After the date the entry shows up in the stale review instead of silently staying selected
- The name keeps the selection digit until the user or the agent changes it
