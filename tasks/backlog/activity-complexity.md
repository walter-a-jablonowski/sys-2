# Complexity of an activity

From the activity model (§6): complexity is the value of a few parameters, not a different kind of
activity.

## What

- Derived by the app: depth and width of the subtree, duration (schedule), number of agents,
  number of dependencies
- Estimated (optional fields or by the agent): uncertainty, goal clarity, reversibility,
  resource scarcity, environment influence
- Use: the editor suggests elements by complexity (a deep, long, uncertain activity gets
  "+ Goal + Assumptions + Phase" offered first), the detail header shows a small complexity mark
